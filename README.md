# OUT OF THE SHADOWS
## Abdulquawiy Olododo

A single-file, premium editorial website concept for a factual public-service archive.

### Deploy
1. Create a new GitHub repository.
2. Add `index.html`.
3. Commit and push.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch.
5. The site is static and requires no build step.

### Before publication
- Replace the third-party image URLs with photographs the site owner has permission to publish.
- Add the final campaign-owned logo/monogram if available.
- Verify every number and date against the preferred primary document.
- Add any official biography, CV, speeches, project documents or approved photographs supplied by the campaign.
- The source room is deliberately retained as part of the experience.

### Design
Black + ivory + restrained gold.
Oversized editorial typography.
Full-bleed photography.
Responsive mobile layout.
Scroll reveal animation.
No framework or dependency beyond Google Fonts.
